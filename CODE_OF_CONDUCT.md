# Code of Conduct

## Our pledge

We want tldw to be a welcoming, harassment-free project for everyone, regardless of
experience, background, or identity.

## Our standards

Examples of behavior that helps:

- Being respectful and constructive in issues, PRs, and reviews.
- Accepting feedback gracefully and giving it kindly.
- Focusing on what's best for the project and its users.

Examples of unacceptable behavior:

- Harassment, insults, or derogatory comments.
- Personal or political attacks.
- Publishing others' private information without permission.

## Enforcement

Maintainers may remove, edit, or reject contributions that violate this code, and may
block repeat offenders. To report an issue, contact the maintainer via a GitHub issue
(for non-sensitive matters) or a private security report.

This Code of Conduct is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
